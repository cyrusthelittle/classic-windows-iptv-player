# Classic Windows IPTV Player v0.7.0

Windows desktop IPTV player. This release rebuilds browsing, the programme guide,
and playback around a single account model.

## Breaking change

- **The phone remote has been removed.** The remote-control feature and its
  `RemoteControlService` are gone. Desktop navigation, playback control, and the
  guide all work as before; only remote control is affected.

## Accounts and data

- Account-scoped favourites, folders, viewing history, and watch progress stored
  under a schema v2 format, with atomic settings and cache writes, backup
  recovery, and a visible notice when recovery happens.
- Protected local files, plus an organisation export and import preview that
  never writes provider credentials to a portable file.
- Safer account editing: drafts survive changing the selected account, Save and
  Open validate every entry before persisting, Cancel discards pending edits,
  and removing an account asks for confirmation.
- Switch accounts without restarting, leaving the current stream playing until
  another account is actually opened.

## Programme guide

- More reliable XMLTV parsing that keeps adjacent programme fields and channel
  aliases, and skips invalid records without losing valid programmes.
- A virtualised two-hour guide timeline with search, Now / Today / date and
  absolute-time navigation, and separate markers for the selected and the
  playing programme.
- A protected, account-scoped guide cache that survives a failed refresh, with
  scheduled refresh, cancel, channel mapping, and account time correction.

## Playback

- Playback preferences for audio, subtitles, and video, saved language
  preferences, session delays, aspect ratio, deinterlacing, and VOD speed.
- A topmost mini player that moves the existing native video host rather than
  recreating it.
- Continue Watching and series progression with Resume / Start Over, season
  selection, ordered episodes, and opt-in next episode.
- Reconnects after a healthy stream drops, and keeps confirmed VOD position
  across retries.

## Performance and navigation

- UI filtering now queries the catalogue search index, the 50,000-item cutoff is
  removed, and the virtualised list creates rows only as they are requested.
- Clearer desktop navigation with primary media choices up front, a labelled
  Ctrl+F search, and secondary playback actions moved into More.

## Diagnostics and privacy

- Credential-safe logging: loose text and URL redaction across query strings,
  Xtream path segments, URL userinfo, and exception and crash output.
- Builds ship with the shared free-to-air accounts, so a fresh install has
  working channels on first launch instead of an empty list.

## Verification

- 135 automated checks pass, covering the core regression suite plus tuner,
  diagnostic redaction, storage, account editing, playback browse and mechanics,
  library navigation, large-library, guide foundation and grid, playback
  preferences, video ownership, and organisation groups.
- The Windows Release build is clean with 0 warnings and 0 errors.

## Upgrade notes

Settings and cache are written under schema v2 on first launch. Keep the release
folder together; do not copy only the EXE, since LibVLC ships alongside it.
